Dados e cópias de segurança

Os dados ficam neste navegador e neste dispositivo. A cópia JSON inclui abastecimentos e passageiros para transferir ou restaurar os dois conjuntos de registros. O HTML exportado guarda uma cópia dos abastecimentos e dos registros de passageiros dentro do próprio arquivo. Depois de adicionar ou editar algo, baixe um novo HTML para atualizar essa cópia; o navegador não consegue regravar automaticamente o arquivo anterior. Restaurar JSON substitui todos os dados atuais após confirmação.
